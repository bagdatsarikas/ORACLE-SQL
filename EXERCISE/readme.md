

Oracle SQL Practice

Hands-on SQL exercises, from basic to advanced, built on the classic SCOTT schema.

Environment

All exercises are written for Oracle FreeSQL, a browser-based Oracle IDE. The SCOTT schema and its data are already loaded, so there is nothing to install or set up.


Learning Path
Level	Topics
Basic	Single-row subqueries · Simple joins · ROWNUM · FETCH FIRST · MINUS · Views
Basic+	IN / ANY / ALL · Multiple-column subqueries · Self join · CONNECT BY · ROWID
Intermediate	Correlated subqueries · GROUP BY problems · Nth highest salary · WITH TIES
Advanced	Multi-table joins (3+) · Analytic functions (RANK, ROW_NUMBER) · Complex hierarchies
