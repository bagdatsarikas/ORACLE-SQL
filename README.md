

# Oracle SQL Mini-Project Portfolio
### Small projects. Practical problems. Growing SQL skills.

Welcome! I’m building this portfolio to show my progress in Oracle SQL—from beginner foundations to advanced problem-solving.

Each mini-project will turn a SQL concept into a practical task, using scenarios such as employee management, customer orders, and sales analysis.

---

## 🧭 The Learning Path

| Stage | Focus | Planned Topics |
| :--- | :--- | :--- |
| **01 · Foundations** | Work with data | SELECT, filtering, sorting, string and numeric functions, dates, conversions, NULL handling, CASE, and aggregation |
| **02 · Build & Manage** | Structure and maintain data | DDL, DML, table constraints, and transaction control |
| **03 · Connect & Explore** | Answer questions across tables | Joins, subqueries, CTEs, set operators, and views |
| **04 · Analyze & Improve** | Solve more complex problems | Analytic functions, rankings, running totals, hierarchical queries, PIVOT, and query tuning |

---

## 🔎 Inside Each Mini-Project

**The problem → The data → The SQL → The result**

Each project will include:

- **A practical question** — What problem are we solving?
- **Sample data** — Tables and setup scripts.
- **My solution** — Oracle SQL queries with clear comments.
- **The result** — Expected output and a short explanation.
- **What I learned** — Key takeaways from the project.

---

## 🎯 What I Aim to Demonstrate

- Breaking a problem into clear SQL steps.
- Writing readable, organized queries.
- Creating and updating data with appropriate constraints.
- Checking results for accuracy.
- Explaining the reasoning behind a solution.
